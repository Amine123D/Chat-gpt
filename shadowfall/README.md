# SHADOWFALL: REALMS OF CHAOS

An original Phaser 3 + TypeScript action-RPG vertical-slice project.

## Run
Requires Node.js 20+.
```sh
npm install
npm run dev
```
Build: `npm run build`

## Controls
- A/D or arrows: move
- Space/W/Up: jump
- J: attack
- K: Sweeping Strike
- L: Forward Rush
- I: Ground Shockwave
- Shift: dodge
- E: interact / collect loot
- Esc: pause

Mobile touch controls are included in-game. Progress is stored locally in the browser.

## Included vertical slice
Vanguard, platform movement, three attack skills, three enemy archetypes, Ashen Warden boss encounter, health and damage, XP/leveling, loot/equipment stats, checkpoint interaction, local save/load, responsive touch controls, procedural graphics, and automated CI workflow.

## Roadmap status
This is the first playable-slice foundation, not the full planned release. Six initial classes, 12 total classes, 50 enemy variants, 15 bosses, eight regions, crafting, merchants, full skill trees, companion progression, localization, and multiple endings are future milestones. No successful build is claimed until GitHub Actions runs.

## Original assets
Sprites and effects are drawn procedurally in code; simple sound effects use Web Audio. No third-party game assets are bundled.
